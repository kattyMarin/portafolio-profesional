Caso de estudio

Alke Wallet – Desarrollo Web con Django


Descripción

Alke Wallet es una aplicación web desarrollada con Python y Django para gestionar información relacionada con clientes, cuentas y transacciones.


Principal desafío

Integrar diferentes componentes de Django, incluyendo modelos, formularios, vistas, autenticación, administración y consultas a la base de datos.


Solución propuesta

Se desarrolló una aplicación utilizando Django, creando modelos y relaciones entre los datos, operaciones CRUD, formularios y funcionalidades para administrar la información.


Herramientas técnicas

Python, Django, SQL, HTML, CSS, base de datos y GitHub.


Principales aprendizajes

Desarrollo web con Django, creación de modelos, relaciones entre datos, operaciones CRUD, formularios, autenticación, Django Admin y consultas a bases de datos.
